# 开发说明

目前仓库包含产品文档、协作模板和开发任务，应用工程由 [#1](https://github.com/jiuwen567/ai-paper-assistant/issues/1) 建立。此时没有可执行的应用启动命令。

## 初始化时补齐

- 客户端与服务端框架、运行版本和依赖锁文件。
- Web、小程序、API 与 Worker 的目录及启动命令。
- PostgreSQL/pgvector、Neo4j、SeaweedFS 的本地配置。
- 数据库迁移、测试、检查和构建命令。
- 示例数据的来源及使用范围。

配置示例只写字段和占位值，真实凭据放本地环境或部署平台。存储数据使用独立目录或卷，不提交 Git。

## 日常开发

先阅读对应 Issue 和设计文档，再建立功能分支。功能、迁移、测试和必要文档一起提交。尚未实现的部分不要写成已提供能力。

模拟与真实调用分开记录。没有完成的联调说明具体缺口，不用通过按钮截图代替完整流程验收。

## 项目管理

阶段和任务见 [开发计划](roadmap.md)，提交流程见 [CONTRIBUTING](../CONTRIBUTING.md)。仓库管理脚本与业务代码分开存放；不能从公开 Issue 内容拼接执行命令。
