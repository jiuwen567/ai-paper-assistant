# 测试与验收

功能开发同步提交测试；最终验收再运行完整双端流程。下面是计划，不是已通过的测试报告。

## 样例

使用有权公开的文献、自制研究记录、作者原稿、材料更正版和反馈意见。样例附来源和使用范围，不提交真实学生论文、访谈身份或未公开研究数据。

第一组样例可包括 8 篇文献、1 份研究记录及更正版、1 份自写原稿、6 条反馈和 30 条原文锚点。规模用于启动验证，实际样本与结果如实记录。

## 必测场景

| 场景 | 通过条件 |
| --- | --- |
| 手机上传，电脑查看 | 两端材料身份和版本一致 |
| 原文回查 | 正确文件版本、位置与上下文可见 |
| 跨项目请求 | 检索、下载和任务接口均拒绝越权 |
| 重复上传或提交 | 不产生重复业务记录 |
| 手机处理旧建议 | 提示版本冲突，不覆盖新稿 |
| Worker 中断 | 任务有恢复路径，不永久停在运行中 |
| 取消或撤权 | 不再发起新调用，迟到结果不发布 |
| 资料中的恶意指令 | 不能扩展工具权限或读取其他资料 |
| 图事件重复或乱序 | 不重复建边，不恢复已撤回关系 |
| 更正材料 | 找到样例中的明确依赖，候选关联另行标注 |
| 清理部分失败 | 显示未完成并可继续，不提前宣称删除完成 |
| 导出时继续编辑 | 文档仍使用固定快照 |

每条实现任务都验证正常流程及至少一个相关失败场景。没有环境、凭据或真实调用时写明未执行，不能算作通过。

## AI 效果

分别统计阅读提取、来源支持、问题诊断和影响候选的正确项、误报、漏报。记录样本量、模型、提示词、材料版本、用时和调用成本。

与直接提问对照时，使用相同材料、任务和模型条件；无法统一的条件明确列出。比较作者核验时间、遗漏问题和返工量，不预先宣称效率提升。

数字和类型校验优先使用程序，语义判断由人工核对。结果没有依据时应提示材料缺口，而不是补编引用、实验或核心论证。

## 演示顺序

手机上传材料 → Web 回查证据 → 审阅作者原稿 → 作者修改 → 更正材料并查看影响 → 手机处理局部建议 → 展示冲突保护 → 导出 Word 和使用说明。

报告链接到实际 Issue、提交和测试记录。模型效果与软件行为分开报告，不用一个“准确率”概括全部能力。


## 阅读模型实测（Issue #9）

2026-11-05 使用本机 Ollama 0.40.14、`qwen3:4b-instruct`（Qwen3-4B-Instruct-2507、Q4_K_M），GPU 推理，上下文 16384，temperature 0，Pi SDK 1.5.0、`reading-v1`。模型文件 SHA256 为 `85e4a5b7b8ef0e48af0e8658f5aaab9c2324c76c1641493f4d1e25fce54b18b9`，来源为 [Ollama 官方模型](https://ollama.com/library/qwen3:4b-instruct)。测试未使用付费接口，token 为服务返回的实际用量，未估算硬件费用。

样例为仓库 `services/backend/core/tests/reading_samples.py` 中完全自制的虚构材料，不是真实研究，也不是效果基准。复现脚本 `evaluate_reading.py` 在 DEBUG 开发环境创建随机专用项目，通过实际上传、解析、题录、任务和 Pi 调用运行三个案例，输出 JSON，最后仅清理该项目的文件与数据。服务需自行配置，模型不随应用部署：

```bash
PYTHONPATH=services/backend uv run python services/backend/core/tests/evaluate_reading.py \
  --model qwen3:4b-instruct --base-url http://127.0.0.1:11434/v1 \
  --output .local/reading-eval.json
```

最终这一轮的结果如下。输入栏不含独立列出的缓存读取，输出包含模型重复生成的工具参数。

| 案例 | 实际效果 | 耗时 | 调用数 | 输入 / 缓存读取 / 输出 token |
| --- | --- | --- | --- | --- |
| 实验甲单篇 | 六项均保留相应原文内容，含数值、对照、重复次数及范围 | 13.94 秒 | 2 | 2957 / 2475 / 877 |
| 实验甲与乙比较 | 两篇各六项提取，条件不同判为不可比，没有换算数值后比较优劣；重复提交两次相同内容只发布一份 | 53.11 秒 | 2 | 2093 / 4930 / 4252 |
| 仅摘要 | 范围仍为摘要；全部六项被标为未提及，其中对象和定性结果属于漏提，其余缺少信息没有补编 | 4.89 秒 | 2 | 595 / 4114 / 281 |

人工核对：前两项共 18 个字段与给定材料对应；摘要应提取的 2 个字段本轮均漏提。比较结论依据可回查，但这些短自制样例不能证明真实长文阅读质量。调试中的早期运行还出现搜索循环、缺少文献、比较结构错误、重复提交及 60 秒调用超时；无有效结果的任务保留失败诊断，没有发布部分摘记。摘要曾在另一轮成功提取对象及定性结果，说明输出存在波动，不能只选成功样例报告。相同内容的重复提交现已幂等处理，但模型仍可能反复生成并耗尽预算。

本轮未做多轮统计、真实长论文、复杂单位/数值语义或不同供应商对照；#19 继续覆盖扩大样本与效果评估。软件已提供来源、数值和范围校验，内容仍默认待核对，不把“原文引文存在”当成“模型解释正确”。
