# 双端使用流程

## 1. 建立项目

作者在 Web 创建项目，填写论文类型、研究目标、截止时间和模板，登记学校或课程的辅助使用要求。小程序通过一次性绑定流程接入同一账号。

## 2. 收集材料

电脑上传文献、原稿和研究材料；手机从聊天文件选择 PDF、DOCX、UTF-8 CSV 或 TXT，并可在证据卡补充短笔记。单文件不超过 20 MB，当前不支持图片上传或扫描件 OCR。文件完成校验后，作者在原文区发起解析；失败时保留状态和重试入口。

同一资料更新时保存新版本，区分补充、更正和撤回。不会仅因上传了新文件，就将旧证据判为错误。

## 3. 阅读与核对

作者选择资料并提出阅读问题。AI 提取研究对象、方法、结果与限制，整理为有来源的摘记或比较表。每项结果能回到具体文件版本和原文位置。

作者核对后补充自己的理解。摘记留在阅读区，不自动进入论文正文。只有摘要、材料缺项或实验条件不可比时，应按原文核对输出；本机小模型仍存在漏提、误报和比较失败，不能把空结果当作无需核验。

## 4. 作者写作

作者填写自己的研究说明，组织章节并编辑正文。系统保存稳定的正文块标识和历史版本，原稿诊断可参考研究说明；当前没有独立的结构生成入口，不替作者补做研究或核心论证。DOCX 导入仅保留顶层文字段落和标题，不恢复图片、表格、公式与原版式。

## 5. 审阅与修改

作者选择原稿范围，系统结合材料给出问题卡：哪里有问题、依据是什么、为什么需要检查、作者可以采取什么行动。

涉及实验、研究结论和关键论证的内容由作者修改。允许的表达建议以原句、建议句和差异展示，作者可接受、编辑后接受或拒绝。

提交时重新检查权限、规则、正文版本和依据状态。手机上的旧建议不能覆盖电脑上刚改好的正文。

## 6. 落实导师意见

作者录入意见并注明来源。AI 提出拆分任务，作者确认后关联章节、补充材料和实际修改。作者标记完成与导师认可分别记录，不能混为同一状态。

## 7. 材料变化后复查

先查询已经登记的证据关系，再由模型补充可能相关的位置。确定依赖和语义候选分开展示。

作者查看新旧依据、处理受影响的段落，并记录理由。有其他有效依据时提示复核，不自动删除论点或改写结论。

## 8. 检查与导出

核对未处理问题、引用、模板和 AI 使用说明，明确确认披露后预览导出。创建快照后，后台按固定的正文、题录和模板版本生成 Word；之后继续编辑不会改变这次交付。当前只附自制示例规则，未验证指定院系格式。下载后在 Microsoft Word 更新整个目录并检查分页、题注与引用，程序读取 DOCX 不能替代这一步。

## 页面安排

| 终端 | 主要入口 |
| --- | --- |
| Web | 我的论文；项目内材料、原稿、审阅、表达、反馈、依据关系、更正影响、披露、导出和清理；环境检查 `/environment` |
| 小程序 | 环境与微信会话、项目列表/详情和上传、阅读与证据、表达建议、修改待办 |
| 公众号 | 管理员配置的“我的论文”小程序入口及“使用帮助”H5；当前命令只生成菜单 JSON |

当前未接订阅消息或公众号消息推送；在项目内主动查询任务与结果。微信绑定、真实编译和真机流程仍待验收，手机尺寸浏览器测试不能代替。

## 演示用例

演示前按[部署说明](deployment.md)建立专用环境和账号，使用自行编写或获准使用的资料；确认项目辅助规则、可用模型及真实微信账号条件。保留每步结果和失败信息，不将预置供应商输出演示成真实模型能力。

1. 在已绑定同一内部账号的手机上传一份自制材料，Web 刷新后核对文件版本与原件；再上传更正版，证明旧文件仍可定位。
2. 在 Web 发起解析、登记题录、选中片段保存证据卡，回查 PDF 页序或 DOCX/TXT/CSV 位置。没有全文时登记摘要范围，不改称全文证据。
3. 作者输入研究说明和自己的原稿，登记三处有依据的关系。发起阅读或诊断，核对原话和问题卡；失败、漏提或误报要现场保留并解释，作者继续自行处理。
4. 在 Web 录入一条复合导师意见，逐项核对候选后建待办；手机更新处理说明，Web 检查同一版本。模型没有正确拆分时手工建立作者待办，并明确记录该模型步骤未通过。
5. 有可用的局部表达建议时，在手机拒绝一条并验证正文不变，再接受另一条并在 Web 核对。另留一条旧建议，先在 Web 改正文，再从手机提交，确认冲突保留当前稿；没有可用建议时该段仍待验收，不能拿空列表代替。
6. 登记材料更正并复查已登记三处及模型候选，由作者记录决定。核对披露，确认固定快照导出；生成期间继续编辑，下载后核对旧快照，在 Word 更新目录并检查排版。

记录实际终端、账号权限、模型及模板版本，每步分别注明通过、失败或未测。当前“真实手机上传—Web 审阅—手机处理—Word 打开”整条演示尚未通过；已验证范围见测试文档，不能以接口或手机尺寸模拟结果补齐。
